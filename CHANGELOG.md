# Changelog

## 0.4.0 — Social Memory & Promise Gameplay

- Added an interactive Social Notebook for all ten recurring students.
- Added separate friendship, trust, respect, strain and combined standing values.
- Added persistent memories with school dates and relationship-specific summaries.
- Added short-term promises with visible due dates and month/year rollover.
- Added direct follow-through choices that improve reliability, trust and ranking score.
- Added broken-promise consequences, strained dialogue and reconciliation routes.
- Added relationship stages from Acquaintance through Closest Friend, plus Cold, Strained and Fractured states.
- Added social-memory contributions to monthly ladder scoring.
- Added `F` keyboard access and a mobile-friendly Social button.
- Added social-memory unit coverage to the standard validation suite.

## 0.1.0 — Vertical Slice

- Added complete canvas-based 2D game shell.
- Added original pixel-art school map, character sprites, portraits, icons and key art.
- Added separate boys' and girls' ladders.
- Added bell-driven class schedule, attendance, lateness, demerits and detention.
- Added ten student NPCs, four teachers and four selectable clubs.
- Added rich dialogue choices, class prompts, missions, events and family-friendly conflicts.
- Added daily summaries, monthly finals, 48-month progression structure and prom ending.
- Added local save/continue, touch controls, audio and static-host deployment files.
